# Portfolio Review Protocol

Compare every supplied candidate against the full portfolio. Return exactly one
machine-readable decision per candidate, using the supplied IDs and contiguous
ranks. Select only evidence-backed `prioritize` decisions and never exceed the
provided experiment capacity.

The riskiest assumption and cheapest credible falsification test are mandatory.
Do not recommend building a product when a landing page, fake door, waitlist,
interview request, or concierge test can resolve demand uncertainty.
