# Security Lead Execution

Use this skill for approved tasks assigned to `security_lead`.

## Procedure

1. Confirm the delegated task is approved.
2. Create or read its subtask plan.
3. Produce threat model, privacy review, or compliance checklist artifacts.
4. Attach mitigations and open risks to the task before completion.
