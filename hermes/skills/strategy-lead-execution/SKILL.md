# Strategy Lead Execution

Use this skill for approved tasks assigned to `strategy_lead`.

## Procedure

1. Confirm the delegated task is approved.
2. Create or read its subtask plan.
3. Produce market, positioning, channel, or competitive artifacts.
4. Attach the artifact and update task status.
